# 🏗️ StroyFix — Умный калькулятор сметы ремонта в Ташкенте

> **StroyFix** — это бесплатный и прозрачный сервис для расчёта сметы стройматериалов и сравнения цен по строительным базарам и магазинам Ташкента (Джами, Куйлюк, Строймаркет).

---

## 🎯 Наша миссия

Помочь новосёлам и жителям Ташкента рассчитать точный объём и стоимость стройматериалов за 1 минуту без сбора личных данных, скрытых комиссий и накруток.

---

## 🚀 Основные возможности (MVP v1.0)

- 📐 **Мгновенный расчёт сметы:** Введите площадь квартиры и тип ремонта — получите ведомость материалов (цемент, кабель, штукатурка, грунтовка и др.).
- 💰 **Честные цены Ташкента:** База средних цен на черновые материалы, электрику и сантехнику с регулярным обновлением.
- 📍 **Сравнение рынков:** Наглядная раскладка по ценам на базарах *Джами*, *Куйлюк* и локальных строймаркетах.
- 📱 **Telegram Mini App Ready:** Адаптирован для идеальной работы на смартфонах внутри Telegram без скачивания.
- 🔒 **100% Приватность:** Сервис не требует регистрации, номера телефона и сбора персональных данных.

## 🛠️ Технологический стек (Tech Stack)

### Frontend
- **Framework:** [Next.js](https://nextjs.org/) (React 19)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **State Management:** Zustand / React Context
- **Icons:** Lucide React

### Backend
- **Framework:** [FastAPI](https://fastapi.tiangolo.com/) (Python 3.11+)
- **Database:** SQLite (для MVP) / PostgreSQL (на будущее)
- **Validation:** Pydantic v2
